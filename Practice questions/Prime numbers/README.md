# Prime Numbers from 1 to 100 (Java)

A simple Java console application that prints all **prime numbers from 1 to 100** using **nested `for` loops** and conditional statements.

## 📌 Features

- Prints all prime numbers between 1 and 100.
- Uses nested `for` loops to check for prime numbers.
- Does not require user input.
- Beginner-friendly Java program.

## 🛠️ Technologies Used

- Java

```

```

## 📖 How It Works

1. Iterates through numbers from `2` to `100`.
2. Assumes each number is prime initially.
3. Checks divisibility from `2` to `num / 2`.
4. If a divisor is found, the number is not prime.
5. Prints the number if it remains prime.
