# Fibonacci Series (Java)

A simple Java console application that prints the **Fibonacci series up to a user-specified limit** using a **while loop**.

## 📌 Features

- Accepts user input from the keyboard.
- Prints the Fibonacci sequence up to the given limit.
- Uses a `while` loop for iteration.
- Beginner-friendly Java program.

## 🛠️ Technologies Used

- Java
- Scanner Class (`java.util.Scanner`)

```
Module1/
└── Fibonacci.java
```

## ▶️ How to Run

   ```bash

   ```

4. Run the program:
   ```bash
   java Module1.Fibonacci
   ```

## 💻 Sample Output

### Example

```
Enter the limit: 20
0 1 1 2 3 5 8 13
```

## 📖 How It Works

1. Reads the limit from the user.
2. Initializes the first two Fibonacci numbers (`0` and `1`).
3. Uses a `while` loop to print each Fibonacci number up to the specified limit.
4. Updates the sequence by calculating the next Fibonacci number.
