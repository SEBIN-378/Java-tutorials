# GCD Calculator (Java)

A simple Java console application that calculates the **Greatest Common Divisor (GCD)** of two numbers using the **Euclidean Algorithm** and a **while loop**.

## 📌 Features

- Accepts two integers from the user.
- Calculates the Greatest Common Divisor (GCD).
- Uses the efficient Euclidean Algorithm.
- Beginner-friendly Java program.

## 🛠️ Technologies Used

- Java
- Scanner Class (`java.util.Scanner`)

## 💻 Sample Output

### Example

```
Enter first number: 24
Enter second number: 36
GCD = 12
```

## 📖 How It Works

1. Reads two integers from the user.
2. Applies the Euclidean Algorithm using a `while` loop.
3. Repeatedly replaces the numbers until the second number becomes `0`.
4. Displays the remaining value as the GCD.
