# Reverse Number (Java)

A simple Java console application that reverses the digits of a given number using a **for loop**.

## 📌 Features

- Accepts a number as user input.
- Reverses the digits of the entered number.
- Uses a `for` loop for the reversal process.
- Beginner-friendly Java program.

## 🛠️ Technologies Used

- Java
- Scanner Class (`java.util.Scanner`)

## 📖 How It Works

1. Reads an integer from the user.
2. Initializes a variable `rev` to `0`.
3. Uses a `for` loop to extract the last digit of the number.
4. Builds the reversed number by appending each extracted digit.
5. Displays the reversed number.
